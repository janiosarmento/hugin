# Project Instructions for AI Agents

This file provides instructions and context for AI coding agents working on this project.

## Session Completion

Work is not complete until `git push` succeeds.

1. Run the quality gates if code changed: tests and lint.
2. Commit the changes with a descriptive message.
3. Push: `git pull --rebase`, then `git push`, then confirm `git status` shows "up to date with origin".
4. Hand off: say what changed and what is still pending in `PENDENCIAS.md`.

- Never stop before pushing; that leaves work stranded locally.
- If the push fails, resolve it and retry until it succeeds.
